# avito-prodavets — 5 агентов для объявления на Авито

Конвейер из 5 узких агентов, который доводит объявление на Авито от идеи до проверенного результата. Вырос из типового гайда «5 промптов для Авито» — каждый промпт усилен до агента с жёсткими правилами качества: без выдуманной статистики, без штампов, с точным счётом символов и честным A/B-тестом.

## Агенты

| Агент | Что делает | Файл с правилами |
|-------|-----------|-------------------|
| 1. Аналитик спроса | 10 востребованных предложений в нише, факты отделены от гипотез, выбор 3 направлений | `references/01-demand-analyst.md` |
| 2. Копирайтер заголовков | 15 заголовков в 3 углах (услуга/боль/преимущество), топ-3 для теста | `references/02-headline-writer.md` |
| 3. Копирайтер описаний | 3 варианта продающего текста до 1000 знаков, без штампов и выдуманных цифр | `references/03-description-writer.md` |
| 4. Методист по фото | план из 7 кадров (услуга→процесс→результат) для съёмки на телефон | `references/04-photo-planner.md` |
| 5. Аналитик результатов | таблица показателей за 7 дней + 3 корректных A/B-теста + правило выбора победителя | `references/05-results-tracker.md` |

Общий список запрещённых штампов и непроверяемых обещаний — `references/banned-phrases.md`.

## Установка

```bash
cp -r avito-prodavets/ ~/.claude/skills/avito-prodavets/
```

Внешних зависимостей и ключей не требуется. Если в проекте уже стоит `wordstat-collector`, агенты 1 и 2 используют его для реальной частотности запросов вместо догадок.

## Как использовать

Вызов одного агента:
- «Разбери мою нишу на Авито — ремонт стиральных машин на дому»
- «Собери заголовки для объявления про <услуга>»
- «Напиши продающее описание для <услуга>»
- «Составь план из 7 фото для объявления»
- «Собери таблицу для проверки объявления за 7 дней»

Весь конвейер подряд:
- «Сделай мне объявление на Авито под ключ для <ниша>» — агенты идут 1→2→3→4→5, после каждого шага — точка согласования перед тем, как двигаться дальше.
