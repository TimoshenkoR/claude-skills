# Telegram переехал

Актуальный скилл, инструкция установки и релизы:
[github.com/TimurUgulava/telegram](https://github.com/TimurUgulava/telegram).

В отдельном репозитории доступны поиск и чтение чатов, отправка с согласованием,
локальный мастер первого входа и помощь с получением API-ключей для Windows и Mac.

Не устанавливайте эту папку как скилл — используйте новый репозиторий.
